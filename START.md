# START – So geht's los

## Spiel starten
`index.html` im Browser öffnen (Doppelklick). Fertig.

Ein Tag dauert 5 Minuten (bei Tempo 1×). Die Uhrzeit steht unten links.

Tasten:
- **Leertaste**: Pause
- **1 / 2 / 3 / 4**: Tempo 1×, 2×, 4×, 8×
- **F**: Vollbild an/aus
